# Note shapes

The two shapes this pack's skills write. Kept here so both skills agree.

## Tidied meeting notes

Four sections, always in this order, always present even when empty:

1. **Decisions** — what is now settled. Each line names the decider.
2. **Actions** — owner, what, by when. An action without an owner is not an action.
3. **Open questions** — what was raised and not resolved, with who cares about it.
4. **Context** — everything else worth keeping: numbers quoted, constraints named, objections voiced.

Then a **Gaps** list: what the notes did not say and a human must fill in.

## Decision log entry

```
## <date> — <the decision in one sentence>

**Decided by:** <names>
**Rejected:** <alternative> — <why not>
**Reversal cost:** cheap | expensive | one-way
**Context:** <two or three lines on what made this the moment to decide>
```

Newest entry at the top of `decision-log.md`. Never edit an old entry: if a decision is
overturned, write a new entry that names the one it replaces.
