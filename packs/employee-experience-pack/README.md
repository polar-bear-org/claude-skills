# Employee Experience Pack

**10 practical AI skills to listen to employees, improve everyday work, and show what happened next.** For founders and managers in agencies and professional-services teams of roughly 20–200.

Find the friction in normal work: confusing handoffs, avoidable waiting, inaccessible processes, uneven workloads, and feedback that never receives a response. This pack focuses on the listening-to-action cycle. Use the existing onboarding and review packs for those specialist processes.

## Start in five minutes

1. Pick a real work problem from the table.
2. Paste its complete portable prompt into your assistant and describe the situation using aliases.
3. Review the artifact with the people affected, choose an owner, and return to check what changed.

## Use with your assistant

**Any text assistant:** paste one file from `portable/` into a chat. Each prompt is self-contained; compatibility means readable instructions, not a native integration or identical model behavior.

**Projects:** add `portable/ALL-SKILLS.md` as a source and paste `PROJECT-INSTRUCTIONS.md` into project instructions. If the assistant cannot retrieve a section, paste the individual prompt. Use approved data-handling practices and avoid shared employee records.

**Agent Skills:** copy selected folders from `skills/` into a supported assistant's skills directory. The folders contain standalone `SKILL.md` instructions. Marketplace installation becomes available after publication; this review edition is not registered publicly.
