# Team Performance Pack

**10 practical AI skills for better retrospectives, team norms and ways of working.** Built for founders and managers in agencies and professional-services teams of roughly 20–200.

Turn delivery friction into a clear working agreement, a useful conversation and a small test. Start with one actual team and one problem. This pack focuses on collective work processes; it does not assess individual performance.

## Start in five minutes

1. Pick a skill below. If the problem is unclear, start with Team Performance Check.
2. Paste its complete file from `portable/` into your assistant and describe the situation using aliases.
3. Review assumptions, take the draft to the people affected, and agree one trial.
4. Return with the actual result to decide what to keep, change or stop.

## Use with your assistant

For a single conversation, paste a complete individual portable prompt. For a project, add `portable/ALL-SKILLS.md` and use `PROJECT-INSTRUCTIONS.md` as its instructions. If retrieval misses a section, paste that skill directly. Text compatibility does not guarantee identical model behavior.

For an Agent Skills-compatible assistant, copy the selected folder from `skills/` into its supported skills location. Individual upload archives, where supplied in the final download, contain the same standalone instructions. Marketplace installation becomes available after publication; this review draft is not yet registered.

## Included

- `skills/`: ten standalone instructions; `portable/`: individual prompts and complete collection.
- [Evidence and sources](resources/evidence-and-sources.md): 14 academic references, findings and limits.
- [Practice lab](resources/practice-lab.md): three fictional worked cases, including a sensitive edge case.
- [Reusable templates](templates/team-workbook.md): charter, retro, handoff, meeting and experiment blanks.
- `PROJECT-INSTRUCTIONS.md`, plugin manifest and existing Polar Bear license.

AI prepares drafts; people facilitate, test facts and decide. Do not upload sensitive personnel or client records to a shared project. This pack is an original practice resource informed by research, not a validated performance intervention.
